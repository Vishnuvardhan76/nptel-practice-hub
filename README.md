\# NPTEL Practice Hub



A web-based practice platform for the NPTEL Conservation Geography course.



\## Features



\- Learn Mode to review weekly questions and correct answers.

\- Practice Mode with Complete, Quick, and Custom tests.

\- Randomized questions and options.

\- Automatic test evaluation and result review.

\- Progress tracking across course weeks.

\- Guest access without login or registration.

\- Active practice session recovery after refresh.



\## Technology Stack



\- \*\*Frontend:\*\* HTML, CSS, JavaScript

\- \*\*Backend:\*\* Python and Flask

\- \*\*Database:\*\* SQLite

\## Run Locally



1\. Install Python.

2\. Install the dependencies listed in `backend/requirements.txt`.

3\. Start the Flask application using the project's configured database.

4\. Open the local address shown in the terminal.



Backend health endpoint: `/api/health`
